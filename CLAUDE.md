# Backlot: notes for Claude

Backlot is a startup product: prompt → finished film (microdrama, short film, web series, YouTube story), plus
quick clips (text, image, characters & products, or a video to remix → 5–15 seconds).
The founder works with Claude as CTO and the whole engineering team. Ship-oriented: small, tested, pushed.

## Current state
The product is feature-complete for launch: prompt → film, quick clips, Basic subscription ($20/month through Lemon
Squeezy, monthly plan credit plus top-ups), 10 GB of storage per customer (kept until they delete it), content checks, billing and account pages, the
company dashboard on `/admin`, the ops dashboard (its own service, see below), password reset, Terms/Privacy drafts, GPU autoscaling on RunPod, and the public
developer API for clips and films (`/api/v1`, the Developers page, `/docs/api`; off until `API_ENABLED=1`). The launch
audit (November 2026: the load freeze, free and flat-fee work, hostile uploads) and the go/no-go list are in
`docs/LAUNCH.md`. What's left is setting up accounts and inputs only the founder can provide (see "Not done yet").
Launch good enough, then fix what customers actually hit: don't polish ahead of real use.

## Working rules
- **GitHub `main` is the source of truth.** Commit and push after every meaningful, green step: the founder
  switches between this repo on a laptop and Claude on the web.
- Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`).
- Never commit secrets. `.env*` files are git-ignored. Document new settings in `engine/env.sample` and
  `docs/DEPLOY.md`.
- Before pushing, run what the change touches (see Tests). CI must stay green.

## Layout
- `engine/`: Node 22 + Hono + Postgres. Entry: `src/index.ts`; routes: `src/server.ts`; pipeline:
  `src/pipeline/*`; money: `src/billing.ts` (credit buckets, plan gate, storage quota) and `src/lemonsqueezy.ts` (payments); RunPod: `src/providers/runpod.ts`, `src/capacity.ts` (the GPU autoscaler).
  Job queue with lanes and per-customer fairness: `src/queue.ts`, `src/jobs.ts`; hourly cleanup: `src/maintenance.ts`; project
  events (webhooks, auto-approval hooks): `src/events.ts`. Database safety (`begin()` timeouts, `retryBusy`, the watchdog):
  `src/db.ts`; inside a transaction always query through its `tx`. Upload hardening: `src/media/ffmpeg.ts`.
  The public API: `src/api/*` (`docs/API.md`).
  Quick clips: `src/pipeline/clips.ts`; content checks: `src/moderation.ts`; the company dashboard: `src/business.ts`
  (web: `src/components/admin/CompanyDashboard.tsx`). The ops dashboard is its own read-only service (`node dist/ops.js`,
  admins only): server `src/ops.ts` + `src/ops/*` (one report per page; pure rules and maths in `src/ops/stats.ts`),
  web `web/src/ops` (a second page, `web/ops/index.html`). The engine records what it reads in `src/telemetry.ts`
  (migration 012: request stats, active days, health snapshots, stage events, content-check verdicts, webhooks).
  Migrations in `db/migrations` (applied on boot, append-only). The story engine (pitch → choose → bible → scene cards
  → scenes → critique → rewrites → breakdown → direction → shots) is described in `docs/STORY-ENGINE.md`: one small,
  checked job per call so a cheaper model still writes well. Prompts in `src/pipeline/prompts.ts`, answer shapes in
  `src/pipeline/schemas.ts`, worked writing examples in `src/pipeline/craft.ts`, budgets, rhythm and checks in
  `src/pipeline/story.ts`. Long films (no length cap) are written season by season with a cheaper bulk model; the
  step-by-step stops (story, script, cast) and paid redo of every step are in `docs/STORY-ENGINE.md`. Judge prompt changes with `npm --prefix engine run eval:story` (mock is free and
  `PROMPT_LOG_DIR=…` shows every prompt; a real run costs about $1–3 per idea and needs `EVAL_CONFIRM=1`).
- `web/`: React + Vite + TanStack Router (file routes in `src/routes`, `routeTree.gen.ts` is generated by the
  build and committed). The API client is `src/lib/engine.ts`. The engine serves the built app.
- `gpu-worker/`: Python RunPod handler. Self-hosted H3 in `backends/h3.py`: the test kit's Ref2VA-VSA recipe (Kablex node,
  4-step LightX2V, sparse Sol attention) run through a private ComfyUI; pins and weight hashes in `h3/models.lock.json`.
  The image is built and published by `.github/workflows/gpu-image.yml`. Setup: `docs/SELF-HOSTED-H3.md`.
- Architecture and invariants: `docs/ARCHITECTURE.md`. Deployment: `docs/DEPLOY.md`. Brand (colours, type, logo,
  the reference boards): `docs/brand/README.md`. Keep new UI on-brand and use the tokens in `web/src/styles.css`.

## Setup (fresh Linux machine)
```bash
apt-get install -y postgresql ffmpeg fonts-dejavu-core   # plus Node 22 and Python 3.11
npm run setup
```

## Tests

npm --prefix web run typecheck && npm --prefix web run lint && npm --prefix web test && npm --prefix web run build

## Local run
`MOCK_PROVIDERS=1 ALLOW_DEV_TOKENS=1 DATABASE_URL=… npm run dev:engine` and `npm run dev:web`, then open
localhost:5173. You're signed in as a dev user, and everything is mocked with no keys needed. The engine
refuses to boot with these flags when `NODE_ENV=production`. Credits, the plan gate and the storage quota are
off unless `ENFORCE_CREDITS=1`. To try billing locally, set it with the `LEMONSQUEEZY_*` variables and send
signed webhooks yourself, like `engine/test/vibe.e2e.ts` does. The ops dashboard: also `npm run dev:ops` (port 8790),
then open localhost:5173/ops/ (the dev user is an admin while `ADMIN_USER_IDS` is empty).

Real providers on a laptop (Anthropic, MiniMax, your RunPod H3 through a tunnel): `docs/LOCAL.md`, `engine/env.local.sample`,
`npm --prefix engine run local` and `preflight:local`.

Desktop app (`desktop/`, branch `backlot-desktop`): Electron around the same engine and web app, with embedded Postgres, bundled
FFmpeg and an automatic cloudflared tunnel for RunPod. See `docs/DESKTOP.md`; check with `npm --prefix desktop test` and
`npm --prefix desktop run smoke` (needs a non-root user). Its FFmpeg lacks `drawtext`, so text drawn into pictures goes through
`textFilter()` in `engine/src/media/ffmpeg.ts`.
